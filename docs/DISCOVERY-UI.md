# 发现页界面

发现页（`src/components/discovery/`）的布局、交互与动效约定。数据从哪来、如何分类见 `docs/ARCHITECTURE.md`。

## 布局

- **悬浮玻璃栏**：不再有固定的通栏。顶部是一枚居中的玻璃胶囊，放品牌和周期切换（今日 / 本周 / 本月）；底部是视图切换（发现 / 收藏，带收藏数）和一颗独立的圆形「配色」按钮。滑动时两者收起，停下约 0.3 秒后带回弹地浮现；页面顶部附近始终显示。
- **每个功能只出现一次**：明暗切换并入「配色」面板（含跟随系统），源码链接放在页脚，去掉了作用重复的刷新按钮（数据是每日快照，加载失败时提示条里有「重新加载」）。
- **工具栏**：搜索框加三个下拉框（语言、排序、历史日期）。设置了筛选的下拉框会高亮，榜单标题旁出现「清除筛选」。
- **两级分类**：第一行是领域（全部 / 开发 / 工具 / 生活 / 学习，带数量），第二行是所选领域的细类，自动换行，不需要横向滑动。「全部」时只列最常见的 8 类，可以展开。选中细类时，带有该次要标签的项目也会出现，计数与结果一致。
- **榜单**：单列排行，按名次从上到下读。每行包含名次、项目图标、项目名与作者、两行中文速览，以及语言、Star、分类、名次变化；右侧是本周期新增 Star。行与行之间用细线分隔，不再是一张张独立卡片。
- **右侧栏（宽度 ≥ 1080px）**：没选中项目时显示本期概况（项目数、中文解读覆盖率、爆发数）、GIT Bot 分类分布（按领域汇总）、刚冒头的项目和快捷键；点击某行后在原位显示项目解读，列表不被遮挡。
- **窄屏**：右侧栏收起，项目解读改为贴底面板，按住顶部横条向下拖可关闭。
- **项目解读里的 GIT Bot 分类卡片**：领域与主分类、次要标签、置信度、判断依据（例如「主题 self-hosted」）、用途、GitHub 主题和所用策略。旧快照没有这些字段时，只显示主分类。
- 数据说明和页脚放在榜单之后。

## 交互

- 整行可点开解读，书签按钮独立；宽屏下再次点击同一行即收起解读。
- 快捷键：`/` 或 `⌘K` 聚焦搜索，`J` / `K` 上下切换项目，`S` 收藏当前项目，`Esc` 关闭解读或退出搜索框。
- 周期、视图、筛选和选中的项目都写进 URL（`?period=weekly&repo=owner/name`），链接可以直接分享。
- 切换周期时，解读里的名次与新增随之更新为该周期的数据。
- 收藏只保存在当前浏览器；底部栏的「收藏」切换收藏视图并显示数量。

## 动效

- 悬浮栏：收起时 0.26 秒加速滑出并略微缩小，弹回时 0.55 秒、带一点过冲，参照 iOS 液态玻璃的手感；键盘焦点在栏内时不会收起。玻璃效果由半透明底色、背景模糊增饱和、顶缘高光和斜向反光组成。
- 其余动效只在状态变化时出现：列表切换时整组淡入（前十行依次错开 18ms），右侧栏换内容时轻微滑入，面板从底部升起，收藏时书签轻弹一下。
- 时长 120–320ms，只动 `opacity` 和 `transform`。背景是一层静止的柔光，不再持续漂移；鼠标经过时不再有跟随光晕。
- 系统开启「减少动态效果」时全部关闭，悬浮栏只淡入淡出、不位移；开启「降低透明度」或浏览器不支持 `backdrop-filter` 时，玻璃改为实色。

## 配色

`theme.ts` 里有 10 套配色（6 套深色、4 套浅色），在 `themes` 数组里加一项，选择器就会自动出现。深色与浅色各自记住上次的选择，「跟随系统」沿用站内已有的明暗设置。

## 约定

- 样式都带 `.radar-app` 前缀。不要使用 `btn` 等与 `uno.config.ts` 快捷类同名的类名，否则会叠加全站样式（例如 `btn` 自带 50% 透明度）。
- 文件分工：`index.tsx` 负责状态与布局，`api.ts` 负责读取数据与收藏，`model.ts` 负责筛选、排序与统计，`category-filter.tsx` 是两级分类筛选，`classified.tsx` 是分类卡片，`row.tsx` 是榜单行，`detail.tsx` 是解读正文和贴底面板，`overview.tsx` 是概况与数据说明，`use-scroll-chrome.ts` 控制悬浮栏的收起与弹回，`theme-picker.tsx` 和 `segmented.tsx` 是通用控件。

## 验证记录

用 Playwright 在 Chromium 里渲染真实组件，按版本记录：

- **单列榜单与侧栏（#8，2026-11-01）**：10 套配色下，正文、作者、Star、名次、增量、分类、更新时间与主按钮文字，按计算颜色检查对比度均不低于 4.5:1。1440、820、390、375 宽度下没有横向溢出、没有脚本报错；快捷键、收藏、搜索、周期切换、面板拖动关闭均实测通过。
- **悬浮玻璃栏（#9，2026-11-02）**：390、1440 宽度下，连续滚动时两栏收起、停下后弹回；静止时顶栏不遮挡搜索框；键盘焦点在栏内时不收起；浅色模式开启「降低透明度」后改为实色。
- **两级分类与分类卡片（#9，2026-11-02）**：1440、390 宽度下，领域与细类计数和筛选结果一致，旧格式快照（没有分类字段）能正常显示。
- 新增元素（领域切换、分类标签、分类卡片、悬浮栏文字）的对比度见下方「对比度复查」。

尚未验证：iPhone 真机上的惯性滚动与贴底面板手势；真实 GitHub 头像（本地验证时屏蔽了头像请求，显示的是首字母占位）。

## 对比度复查

2026-11-02 在 10 套配色下复查 #9 新增的元素，按真实背景层叠后的颜色计算（悬浮栏按其压在页面底色上计算）：领域切换（选中与未选中、计数）、分类标签与计数、「展开全部分类」、分类卡片里的主分类与领域、顶栏周期切换、品牌文字、底栏标签。新流程首次采集后，又用真实数据补测了分类卡片里的次要标签、判断依据、用途和侧栏的分类分布。所有元素最低为 5.09:1（「薄荷」主题的领域计数），全部不低于 4.5:1。
