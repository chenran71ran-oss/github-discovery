# 发现页界面

发现页（`src/components/discovery/`）的布局、交互与动效约定。只涉及前端，数据格式、采集和部署不变。

## 布局

- **顶栏**：品牌、周期切换（今日 / 本周 / 本月）、收藏、刷新、配色、明暗、源码。手机上周期切换单独占一行，随顶栏吸顶。
- **工具栏**：搜索框加三个下拉框（语言、排序、历史日期），下面是一行可横向滚动的分类标签，右侧渐隐提示还有更多。设置了筛选的下拉框会高亮，榜单标题旁出现「清除筛选」。
- **榜单**：单列排行，按名次从上到下读。每行包含名次、项目图标、项目名与作者、两行中文速览，以及语言、Star、分类、名次变化；右侧是本周期新增 Star。行与行之间用细线分隔，不再是一张张独立卡片。
- **右侧栏（宽度 ≥ 1080px）**：没选中项目时显示本期概况（项目数、中文解读覆盖率、爆发数）、刚冒头的项目、语言分布（点一下即按语言筛选）和快捷键；点击某行后在原位显示项目解读，列表不被遮挡。
- **窄屏**：右侧栏收起，项目解读改为贴底面板，按住顶部横条向下拖可关闭。
- 数据说明和页脚放在榜单之后。

## 交互

- 整行可点开解读，书签按钮独立；宽屏下再次点击同一行即收起解读。
- 快捷键：`/` 或 `⌘K` 聚焦搜索，`J` / `K` 上下切换项目，`S` 收藏当前项目，`Esc` 关闭解读或退出搜索框。
- 周期、视图、筛选和选中的项目都写进 URL（`?period=weekly&repo=owner/name`），链接可以直接分享。
- 切换周期时，解读里的名次与新增随之更新为该周期的数据。
- 收藏只保存在当前浏览器；顶栏的「收藏」按钮切换收藏视图并显示数量。

## 动效

- 只在状态变化时出现：列表切换时整组淡入（前十行依次错开 18ms），右侧栏换内容时轻微滑入，面板从底部升起，收藏时书签轻弹一下。
- 时长 120–320ms，只动 `opacity` 和 `transform`。背景是一层静止的柔光，不再持续漂移；鼠标经过时不再有跟随光晕。
- 系统开启「减少动态效果」时全部关闭；开启「降低透明度」或浏览器不支持 `backdrop-filter` 时，顶栏改为实色。

## 配色

`theme.ts` 里有 10 套配色（6 套深色、4 套浅色），在 `themes` 数组里加一项，选择器就会自动出现。深色与浅色各自记住上次的选择，「跟随系统」沿用站内已有的明暗设置。

## 约定

- 样式都带 `.radar-app` 前缀。不要使用 `btn` 等与 `uno.config.ts` 快捷类同名的类名，否则会叠加全站样式（例如 `btn` 自带 50% 透明度）。
- 文件分工：`index.tsx` 负责状态与布局，`row.tsx` 是榜单行，`detail.tsx` 是解读正文和贴底面板，`overview.tsx` 是概况与数据说明，`theme-picker.tsx` 和 `segmented.tsx` 是通用控件。

## 验证

- 10 套配色下，正文、作者、Star、名次、增量、分类、更新时间与主按钮文字，按计算颜色检查对比度均不低于 4.5:1。
- 在 1440、820、390、375 宽度下渲染真实组件，没有横向溢出，也没有脚本报错；快捷键、收藏、搜索、周期切换和面板拖动关闭都已在浏览器里实测。
- 项目图标使用 GitHub 头像，本地验证时屏蔽了头像请求，显示的是首字母占位。
