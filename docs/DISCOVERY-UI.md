# 发现页界面

发现页（`src/components/discovery/`）的布局、交互与动效约定。数据从哪来、如何分类见 `docs/ARCHITECTURE.md`。

## 布局

- **悬浮玻璃栏**：不再有固定的通栏。顶部状态栏是一枚居中的玻璃胶囊，放品牌、周期切换（今日 / 本周 / 本月）、明暗切换和账号头像（点开是账号菜单：成员管理（仅管理员）、退出登录）；底部是视图切换（发现 / 收藏，带收藏数）。滑动时两者收起，停下约 0.3 秒后带回弹地浮现；页面顶部附近、以及用键盘切换项目时始终显示。
- **每个功能只出现一次**：明暗切换只在顶部状态栏，源码链接放在页脚，没有刷新按钮（数据是每日快照，加载失败时提示条里有「重新加载」）。
- **工具栏**：搜索框加三个下拉框（语言、排序、历史日期）。设置了筛选的下拉框会高亮，榜单标题旁出现「清除筛选」。
- **搜索**：按空格拆成多个词，每个词都要命中、不分先后（「AI 记账」）；不区分大小写与全角半角；搜项目名、作者、简介、中文简介、适用场景、语言、技术栈、分类、用途和 GitHub 主题。搜索只在当前周期和当前筛选内进行；如果领域 / 分类 / 语言筛选挡住了匹配项，标题旁会提示「筛选之外还有 N 个匹配，查看全部」。
- **两级分类**：第一行是领域（全部 / 开发 / 工具 / 生活 / 学习，带数量），第二行是所选领域的细类，自动换行，不需要横向滑动。「全部」时只列最常见的 8 类，可以展开。选中细类时，带有该次要标签的项目也会出现，计数与结果一致。
- **榜单**：单列排行，按名次从上到下读。每行包含名次、项目图标、项目名与作者、两行中文速览，以及语言、Star、分类、名次变化；右侧是本周期新增 Star。行与行之间用细线分隔，不再是一张张独立卡片。
- **右侧栏（宽度 ≥ 1080px）**：不显示滚动条，内容超出时底部渐隐提示；每一块内容是一张小卡片，左上小标题、右上小状态框（如「已更新 11/2 15:58」「用途优先」「2 个」「机翻」）。没选中项目时显示本期概况（项目数、中文解读覆盖率、爆发数）、GIT Bot 分类分布（按领域汇总）、刚冒头的项目和快捷键；点击某行后在原位显示项目解读，列表不被遮挡。
- **窄屏**：右侧栏收起，项目解读改为贴底面板，按住顶部横条向下拖可关闭。
- **项目解读里的 GIT Bot 分类卡片**：领域与主分类、次要标签、置信度、判断依据（例如「主题 self-hosted」）、用途和 GitHub 主题，状态框显示规则判断还是模型判断。旧快照没有这些字段时，只显示主分类。
- 「在 GitHub 打开」与「收藏」固定在侧栏和底部面板的最下方，内容再长也不用滚到底。
- 数据说明和页脚放在榜单之后。

## 交互

- 整行可点开解读，书签按钮独立；宽屏下再次点击同一行即收起解读。
- 快捷键：`/` 或 `⌘K` 聚焦搜索，`J` / `K` 上下切换项目，`S` 收藏当前项目，`Esc` 关闭解读或退出搜索框。大小写、大写锁定都可以；中文输入法组字时不触发；有弹层打开时不穿透到后面的榜单。
- `J` / `K` 切换时，键盘焦点跟着高亮的行走，之后按 Enter / 空格作用在同一行；选中的行滚到两条悬浮栏之间，不会被遮住。
- 周期、视图、筛选和选中的项目都写进 URL（`?period=weekly&repo=owner/name`），链接可以直接分享。
- 切换周期时，解读里的名次与新增随之更新为该周期的数据。
- 登录后收藏保存在账号里（D1），换设备也在；第一次登录时自动把这台浏览器里已有的收藏并进账号（只做一次，账号里已有的不覆盖）。收藏时先更新界面，同步失败再恢复并提示。没有账号层的本地开发仍存在浏览器里。底部栏的「收藏」切换收藏视图并显示数量。

## 动效

- 悬浮栏：以淡入淡出为主，只带一点位移（12–14px）和缩放；收起 0.32 秒，浮现约 0.4–0.5 秒、缓出、不过冲。连续滑过约 24px 才收起，轻微滚动不会闪；停下约 0.26 秒后浮现。键盘焦点在栏内时不会收起。玻璃效果由半透明底色、背景模糊增饱和、顶缘高光和斜向反光组成。
- 明暗切换：太阳与月亮是同一个图形，切换时圆心缩放、月牙咬口滑入、光芒旋转收起；同时新主题从按钮位置圆形展开（View Transitions）。浏览器不支持或开启「减少动态效果」时直接切换。
- 其余动效只在状态变化时出现：列表切换时整组淡入（前十行依次错开 18ms），右侧栏在概况与解读之间轻微滑入、用 J / K 换项目时只淡入，面板从底部升起，收藏时书签轻弹一下。
- 时长 120–320ms，只动 `opacity` 和 `transform`。背景是一层静止的柔光，不再持续漂移；鼠标经过时不再有跟随光晕。
- 系统开启「减少动态效果」时全部关闭，悬浮栏只淡入淡出、不位移；开启「降低透明度」或浏览器不支持 `backdrop-filter` 时，玻璃改为实色。

## 主题

只有一套主题，分深浅两种模式，强调色是 Windows 11 的系统蓝（深色 `#4CC2FF`、浅色 `#0067C0`）。颜色令牌写在 `style.css` 的 `.radar-app[data-mode="dark"]` 与 `[data-mode="light"]` 下，其余颜色都由 `--bg`、`--ink`、`--accent` 派生。首次访问跟随系统，手动切换后记住选择（`localStorage` 的 `color-scheme`）。

切换为什么要特别处理：整页约 250 行榜单都从主题变量派生颜色，旧版换主题时，浏览器在一帧里重新计算全部样式，同时几百个元素各自开始颜色过渡，而且每一行都会重新渲染，所以一卡一卡的。现在的做法：
- 颜色写成静态的 CSS，不再用行内变量和可动画的 `@property`；
- 切换时暂停所有元素自己的过渡（`html.theme-switching`），由 View Transitions 冻结旧画面、一次性换好、再圆形展开；
- 榜单行是 `memo` 组件、回调保持稳定，切换明暗时不再重新渲染；
- 屏幕外的行用 `content-visibility: auto` 跳过样式与布局计算。

## 约定

- 样式都带 `.radar-app` 前缀。不要使用 `btn` 等与 `uno.config.ts` 快捷类同名的类名，否则会叠加全站样式（例如 `btn` 自带 50% 透明度）。
- 文件分工：`index.tsx` 负责状态与布局，`api.ts` 负责读取数据与收藏，`model.ts` 负责筛选、排序与统计，`category-filter.tsx` 是两级分类筛选，`classified.tsx` 是分类卡片，`row.tsx` 是榜单行，`detail.tsx` 是解读正文和贴底面板，`overview.tsx` 是概况与数据说明，`use-scroll-chrome.ts` 控制悬浮栏的收起与弹回，`theme.ts` 与 `mode-toggle.tsx` 是明暗切换，`section.tsx` 是带状态框的小标题，`segmented.tsx` 是分段控件。

## 验证记录

用 Playwright 在 Chromium 里渲染真实组件，按版本记录：

- **搜索与悬浮栏动效（2026-11-02，生产构建）**：英文、中文（含输入法组字）、`/` 快捷键在桌面和手机上都能过滤；「AI 浏览器」两个词得到 7 个结果（之前按整句匹配为 0）；全角「ＢＲＯＷＳＥＲ」与 browser 结果相同；「生活」筛选下搜 browser 只有 1 个，提示筛选外还有 14 个，点开后得到全部 15 个；输入法把 `/` 报成 Process 时仍能打开搜索。滚动 15px 悬浮栏不收起，连续滚动时淡出，停下后淡入。

- **单一主题与键盘修复（2026-11-02）**：
  - 明暗切换时主线程阻塞（Long Tasks 合计）：旧版平均约 1.8–2.2 秒、最长单个任务约 0.5 秒；现在平均 117 毫秒、最长 73 毫秒（同一容器、各 4 次）。容器没有 GPU，帧间隔受软件渲染影响，所以用主线程阻塞比较。
  - 键盘：点选一行后按 `J`，焦点跟着高亮走；`Shift+J` 有效；连按 25 次 `J` 再按 25 次 `K`，选中行始终在两条悬浮栏之间，悬浮栏没有收起；底部面板打开时，`S` 和 `/` 不会穿透。
  - 深浅两种模式下，榜单、侧栏小标题与状态框、分类卡片、主按钮、底栏与顶栏文字对比度均不低于 4.5:1（最低 5.47:1；改用系统蓝后复查，最低 5.67:1）。
  - 不支持 View Transitions 与开启「减少动态效果」时，切换直接完成，没有残留状态。

- **单列榜单与侧栏（#8，2026-11-01）**：10 套配色下，正文、作者、Star、名次、增量、分类、更新时间与主按钮文字，按计算颜色检查对比度均不低于 4.5:1。1440、820、390、375 宽度下没有横向溢出、没有脚本报错；快捷键、收藏、搜索、周期切换、面板拖动关闭均实测通过。
- **悬浮玻璃栏（#9，2026-11-02）**：390、1440 宽度下，连续滚动时两栏收起、停下后弹回；静止时顶栏不遮挡搜索框；键盘焦点在栏内时不收起；浅色模式开启「降低透明度」后改为实色。
- **两级分类与分类卡片（#9，2026-11-02）**：1440、390 宽度下，领域与细类计数和筛选结果一致，旧格式快照（没有分类字段）能正常显示。
- 新增元素（领域切换、分类标签、分类卡片、悬浮栏文字）的对比度见下方「对比度复查」。

尚未验证：iPhone 真机上的惯性滚动与贴底面板手势；真实 GitHub 头像（本地验证时屏蔽了头像请求，显示的是首字母占位）。

## 对比度复查（#9，10 套配色时期）

2026-11-02 在 10 套配色下复查 #9 新增的元素，按真实背景层叠后的颜色计算（悬浮栏按其压在页面底色上计算）：领域切换（选中与未选中、计数）、分类标签与计数、「展开全部分类」、分类卡片里的主分类与领域、顶栏周期切换、品牌文字、底栏标签。新流程首次采集后，又用真实数据补测了分类卡片里的次要标签、判断依据、用途和侧栏的分类分布。所有元素最低为 5.09:1（「薄荷」主题的领域计数），全部不低于 4.5:1。
