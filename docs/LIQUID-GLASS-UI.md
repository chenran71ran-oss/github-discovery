# 液态玻璃界面

发现页（`src/components/discovery/`）的紧凑榜单界面，带液态玻璃质感、项目图标、10 套配色，并针对 iPhone 做了适配。只改前端，数据格式、采集和部署不变。

## 内容

- **紧凑榜单**：每行有名次、项目图标、项目名、两行中文速览、语言、Star、增长数。宽屏两列，手机单列；可切换「按用途分栏」。
- **项目图标**：使用仓库所有者的 GitHub 头像（`github.com/<owner>.png`）。加载中或失败时显示按所有者着色的首字母方块，列表高度不会跳动。
- **「爆发」标记**：周期新增 Star 占总数的比例与绝对增量同时达标才显示。规则在 `shared/discovery.ts` 的 `breakoutRules`，有测试覆盖。
- **液态效果**：背景光晕、带高光边缘的玻璃面板、会回弹的滑动高亮、收藏和按压的弹性动画、换配色时颜色渐变。
- **配色**：`theme.ts` 里 10 套（6 深 4 浅）。新增主题只需在 `themes` 数组加一项，选择器自动出现。深色与浅色各记住上次选择，「跟随系统」沿用站内已有的明暗设置。

## iPhone

- `index.html` 增加 `viewport-fit=cover`，并支持添加到主屏幕。
- 手机上有悬浮玻璃底栏，配色面板和项目详情是贴底面板；输入框和下拉框字号 16px，避免 Safari 聚焦时自动放大。
- 刘海、灵动岛和底部横条用 `env(safe-area-inset-*)` 避让；`theme-color` 跟随当前配色。
- 背景光晕的漂移只在有鼠标的设备上开启，iPhone 上保持静止以省电。
- 系统开启「降低透明度」或浏览器不支持 `backdrop-filter` 时，玻璃自动改为实色。

## 验证情况

- 对比度：10 套主题在真实渲染像素上，正文、摘要、作者、Star、增长数、选中标签等文字均不低于 4.5:1。
- 已在 1440、390、375 宽度渲染真实组件，无横向溢出、无脚本报错。
- 合约测试在本地通过；`pnpm build`、`pnpm typecheck` 以 CI 为准。
- 项目图标用的是 GitHub 头像，本地验证时用占位图代替，真实头像需在线上确认。
